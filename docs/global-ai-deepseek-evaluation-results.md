# 全局 AI DeepSeek 回答评测记录

日期：2026-09-06。候选模型：`deepseek-v4-flash`。当前结论：**未通过第一版发布门槛**。

## 固定边界

- A01–A03各独立运行3次，只发送固定虚构投资账户、确认记忆和现金流示例。
- 不导入Django，不读取网站数据库、NAS或生产资料；账本与投资模块不对账、不合并。
- 本轮累计预算硬上限1美元。修正后单次完整运行的理论最高费用为0.6072美元，加上第一次冒烟仍低于1美元。
- 请求不重试、不跟随重定向；运行号在第一次请求前持久化，不能换号绕过结果不明状态。
- 自动检查只标出客观缺词和危险措辞，模型是否通过必须由人工审阅。

## 第一次冒烟

运行号：`deepseek-v4-flash-20260906-r1`。

执行器收到2次确定的服务端响应，第二次回答因500 token输出上限以`length`结束。旧执行器按停止规则
终止整条轨迹，没有保留截断正文，因此A01–A03均不能评分。未出现网络结果不明，也没有自动重发。
按请求前保守预留计算，本次费用占用上限为0.004673美元；由于旧执行器没有在轨迹完成前保存usage，
不能把它写成供应商实际账单金额。

## 修正与复验

执行器已把单次输出上限改为2,000 token；即使跑满30次请求，理论最高费用仍低于已授权总额。
模型以`length`结束时会保留已有正文、usage、终止原因和工具审计，并继续作为不完整样本供人工查看，
不会丢失整条轨迹。新增截断留档测试后，隔离原型与评测执行器共29项测试通过，dry-run确认发送清单
仍只包含虚构数据。

用户随后明确允许将本轮累计预算放宽至1美元。为避免重发结果不明的A03第1条，补充运行只执行
A03第2、3条。两条均完成，使用6次请求，完整回答用量估算0.005573美元。

## 后续决定

先修改工具说明，让A01只取投资账户与目标边界，避免无关现金流数据进入上下文；在留出案例中明确
检查“追加本金不能修复或掩盖历史投资回撤”。提示版本改变后，不把本轮分数沿用为新版本结果。
完成这些本地改进后，再用第二个候选模型做同样的有限对照。当前结果不支持把DeepSeek接到全局AI
网页，也不支持部署Codex Harness。

## 新版同条件对照

加入明确的工具用途、禁止用注资修复历史回撤的规则和A04留出案例后，DeepSeek用相同的2,000 token
上限重跑。A01–A03九条及A04一条全部完成，共29次请求，公开峰值单价估算0.023964美元，核心轨迹
平均约8.6秒。

完整性改善没有消除事实错误：A01第2条把80万元账户的现金、股票、债券分别写成12.5万、62.5万、
25万；A03第2条把期初100万误写成10万；另有答案在缺少依据时使用“偏进取”“风险倾向偏高”。
A04正确说明外部注资不能抹掉20%的历史最大回撤。由于财务金额事实错误属于阻断项，DeepSeek新版
仍未通过。
