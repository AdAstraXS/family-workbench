# 全站前端一致性检查（2026-10-03）

## 范围与结果

检查家庭概览、投资组合、家庭账本、投研、投资动态、期权车轮、港股打新、投资笔记、
知识中心、在线书库、交易复盘、AI 情报、宏观数据、AI 检索与问答和运行监控共 15 个模块入口。
生产页面用于检查真实内容；隔离环境用于改动后的布局、色系、键盘和空状态验收。
二级页面抽查了解公司、读书计划及模块导航。此次检查不等同于遍历全部详情 URL 或业务流程。

| 问题 | 修复后行为 |
| --- | --- |
| 投研强制 1280px、动态内层 1180px，其他模块另设宽度 | 外层页面统一最大 1560px，顶栏、正文、页脚共用水平留白；阅读正文仍可保留自身窄栏 |
| 短页面切换为长页面时水平位置变化 | 为滚动条预留稳定空间 |
| 研究筛选、动态导航、笔记和监控残留固定绿色或蓝色 | 导航、主按钮、卡片与辅助文字跟随用户选择的四种色系 |
| 部分辅助文字偏浅 | 加深四种色系的辅助文字颜色 |
| 模块首页堆叠返回首页按钮，研究页重复导航 | 首页保留统一工作台导航；子页保留有效上一级，避免相同目标重复按钮；研究沿用自己的面包屑 |
| 投资动态缺少当前子栏目提示 | 新闻、主题、动态、关注设置、收藏、来源等显示当前栏目 |
| 手机研究筛选压缩输入框，监控末端日期溢出 | 搜索框独占一行、选项横向滚动；图表末端日期收在图表范围内 |
| 快速查找未直接聚焦输入，移动菜单焦点不明确 | 查找聚焦搜索框，菜单聚焦当前模块，Esc 关闭菜单后回到开关 |
| 点击弹窗内部留白会关闭 | 仅点击弹窗外背景时关闭 |
| 在线书库仍标为筹备中 | 描述更新为书籍、阅读计划与批注 |

警告、证据判断、盈亏颜色和书籍封面保留原有语义。未改变数据权限、财务计算、自动抓取、
阅读归档规则或业务模型；本次前端修改没有数据库迁移，也没有新增依赖。

## 验证

- PostgreSQL 分组回归：`ipo portfolio` 317 项通过；家庭工作台、概览、研究导航与公司工作区、
  投资动态、阅读共 190 项通过。合计 507 项，均无跳过。
- 合入投资新闻后续排队修复后，再复跑投资动态 111 项测试，全部通过。原始日志保存在本地验收输出目录，
  不提交生产资料、日志或数据库到仓库。
- `manage.py check`、`makemigrations --check --dry-run`、`git diff --check` 完成。
  本地隔离环境没有配置 OneNote 凭据与生产加密密钥，因此系统检查保留两条配置警告。
- 15 个入口检查桌面和 390px 手机布局；另抽查 320px、768px、1920px。
  1920px 下顶栏与主页面均为 1560px，动态内容与共同内边距对齐。
- 四种色系检查研究、投资动态、在线书库和监控；移动菜单、快速查找、弹窗背景关闭及
  键盘 Esc 行为均已实测。监控手机页面修复后不再横向溢出。
- 整组 PostgreSQL 测试曾触发既有跨应用序列化测试夹具冲突；分组运行上述套件均通过。
  未为规避测试夹具问题修改产品代码。
