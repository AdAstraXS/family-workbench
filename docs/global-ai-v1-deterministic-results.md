# 全局 AI 第一版确定性评测结果

日期：2026-09-05。运行范围：本地隔离 SQLite 测试数据库。模型调用：0。

## 结果

20个规划案例已经固定到可执行清单，并由一个命令统一列出和运行。当前正式只读服务能够执行其中
11例：F01–F06、K01–K05，本轮全部通过。其余9例保留在同一清单中并明确标记为待实现，未计为通过。

| 范围 | 数量 | 本轮状态 | 说明 |
| --- | ---: | --- | --- |
| 财务 F01–F06 | 6 | 通过 | 使用真实账本与投资只读服务、虚构数据 |
| 知识 K01–K05 | 5 | 通过 | 使用真实知识检索与精确版本服务、虚构数据 |
| 记忆/分享 M01–M04 | 4 | 待实现 | 尚无正式会话、记忆、外发授权和回答分享服务 |
| 生命周期 L01–L02 | 2 | 待实现 | 尚无正式异步请求、取消和用量服务 |
| 回答质量 A01–A03 | 3 | 待模型 | 需要候选模型回答与人工盲评，当前不应模拟通过 |

F01–F06确认账本和投资模块保持独立，草稿不会成为正式结论，历史账户仍保留，缺汇率或不完整估值
不会生成完整总额或比例。K01–K05确认检索只返回当前成员有权资料，精确版本可回查，来源或资料撤权
会覆盖陈旧索引，原文中的越权指令不会扩大读取或写入能力。

## 复跑

```text
python manage.py evaluate_global_ai_v1
python manage.py evaluate_global_ai_v1 --list --json
```

命令使用 Django 临时测试数据库，不读取 NAS 生产数据，不调用任何模型。输出包含固定案例清单、
虚构资料标识与 SHA-256 哈希；案例和资料发生变化时，代码评审应同时核对哈希变化。

## 当前结论

三个模块的只读工具边界已经具备进入下一阶段的条件。当前结果只证明数据选择、金额完整性、权限和
版本引用的后端约束，不证明模型回答质量、对话隔离、记忆治理、任务幂等或分享安全。下一阶段应先
实现正式会话与请求生命周期，使 M01–M04 和 L01–L02 可执行；候选模型与预算确认后再运行 A01–A03。
