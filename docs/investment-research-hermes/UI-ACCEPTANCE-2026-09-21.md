# 投研页面离线验收（2026-09-21）

在隔离的本地 Docker 样例站点验收，使用临时 SQLite 数据库、MSFT/AAPL 模拟 SEC 10-K 正文和模拟 AI 返回；没有访问生产数据库、调用真实模型或部署 NAS。该站点没有使用 localhost:8000 的已有容器，因为它挂载的是另一份工作目录。

## 已走通的页面流程

- 研究首页可选择“先了解一家公司”；无需持仓、持有理由或先写假设，分别为 MSFT 和 AAPL 建立私密探索档案。两家公司使用同一入口，无逐公司 IR 规则。
- MSFT 官方资料页显示已保存的正文版本；从精确引用打开原文时，回到同一版本并高亮对应句子。页面区分资料已归档与正文已取得。
- AI 草稿表单在未勾选本次发送确认时阻止提交。确认后用模拟模型生成带引用的探索草稿；引用回到保存的原文。草稿没有自动形成正式判断，成员手动保存第一版判断后，档案才进入正式版本。
- 发现并修复历史草稿的语境漂移：探索草稿生成后若保存正式判断，旧草稿仍应按生成时“尚无判断”的语境显示，不应改称支持/削弱当前判断。正文获取时间改为本地可读时间；档案中最初记录的折叠标题也改为适用于探索后补写首版判断的文案。
- 桌面和窄屏检查了首页、档案、资料、正文及草稿的层级和操作。另一位同家庭成员的研究列表为空，直接打开原成员档案及草稿均返回 404。
