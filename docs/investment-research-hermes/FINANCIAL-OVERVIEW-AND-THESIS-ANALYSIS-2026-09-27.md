# 公司财务概览与个人判断分析

## 页面路径

公司研究档案先展示成员当前判断，随后依次进入“财务概览”和“AI 综合分析”。官方资料页负责检查 SEC／IR 目录并按需保存正文；打开研究页面不会联网或写库。“更新 SEC 文件目录”“更新公司 IR 材料目录”只检查文件列表，不下载全部正文，旁边的问号说明了作用。

财务概览从选定的、已归档 SEC 10-K 原件提取最近三个完整财年的整公司事实。每个显示的基础值必须同时通过 XBRL 标签、期间、USD 单位、无维度、金额唯一性和保存正文 Item 8 引文校验；不满足时留空并给出原因。其他年度 10-K 可在相同证券及 CIK 下补充期末现金和债务；若同期间两份年报金额不同则留空待核。利润率、同比增长和简化自由现金流使用 `Decimal` 由已核对值计算，列出基础值引用。业务收入单列，不能相加或直接跨公司比较。

“富途财务对照”是独立页面。成员主动更新时，通过 OpenD 请求最近三个完整财年的利润表、资产负债表、现金流量表、主要指标和最新年度主营构成，保存最后一次成功快照。SDK 浮点数在接收边界转成十进制字符串；GET 只读取快照。仅在财年结束日和 USD 币种一致时，把少量同名字段与 SEC 并列，字段 ID、原始名称和币种保留；并列不意味着口径一致。富途权限、字段覆盖和真实返回仍须在可达 OpenD 环境验收。官方接口文档：[财务报表](https://openapi.futunn.com/futu-api-doc/en/quote/get-financials-statements.html)、[主营构成](https://openapi.futunn.com/futu-api-doc/en/quote/get-financials-revenue-breakdown.html)。

AI 综合分析让成员选择 1–3 个固定正文版本片段（每段最多 8,000 字）和一个获准的文本模型，逐次确认发送个人判断。输出必须逐项覆盖假设及问题，标出支持、反证、混合或证据不足；有结论的条目须引用本次传入的原文片段。服务端验证引用 ID 并保存当时判断版本、文件版本、范围和哈希。结果是私密草稿，不自动更改正式判断，不提供交易指令。很长的年报章节仅分析页面明确显示的开头片段，因此不能声称已分析整份文件。

## 核对与限制

- 目前 SEC 数字只覆盖美元 10-K 且依赖可解析的 iXBRL 与 Item 8 正文；缺失、重列冲突和不一致标签会留空。不能把空白解释成零。
- 固定资产现金支出与经营现金流之差称“简化自由现金流”，不包含所有资本投入，也不是公司报告的非 GAAP 指标。融资租赁和复杂债务构成需要原文补充核对。
- 富途的归母净利润等规范化字段与 SEC 整公司净利润可能不同；对照页保留两者定义提示，不自动将差额判为错误。
- 离线使用合成 10-K、模拟富途响应和模拟文本模型验证了引用、财务计算、权限、无 GET 联网和失败提示；真实 OpenD 权限、真实 SEC 年报覆盖率及模型结果质量需要上线后逐项验收。
