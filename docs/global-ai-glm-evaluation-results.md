# 全局 AI GLM-5.3 Flash 评测记录

日期：2026-09-06。候选模型：`glm-5.3-flash`。结论：**财务边界较好，但完成率和延迟未通过。**

## 接入与数据边界

- 使用智谱开放平台充值余额的通用端点与OpenAI兼容协议；模型列表确认账号可用。
- API Key仅从项目外的本地 `.env` 读取，不写入结果、源码或日志。
- 只发送固定虚构投资账户、确认记忆和现金流示例，不读取Django、NAS或生产资料。
- A01–A03各三次；另用A04检查外部注资是否被错误当成回撤恢复。
- 单次等待120秒，不重试，不跟随重定向；请求体20,000字符、输出2,000 token。

## 结果

| 案例 | 完整结果 | 主要表现 |
| --- | ---: | --- |
| A01 | 3/3 | 金额、目标和未知项正确；只调用投资快照与确认记忆 |
| A02 | 1/3 | 完整样本正确；一条截断在示例中，一条第二轮正文为空 |
| A03 | 2/3 | 两条正确拒绝保证并拆分15万投入与5万收益；一条最终正文为空 |
| A04 | 1条可评分 | 正确保留20%历史最大回撤，但“当前回撤为0”未按资金流调整，可能误导 |

核心九条中只有六条完整。完整回答没有出现DeepSeek首轮“注资可能压回回撤”的错误，工具选择也更
准确；但三条输出不完整已经违反发布门槛。核心轨迹平均约77秒，约为新版DeepSeek的9倍，也不适合
当前交互页面。

GLM共尝试26次请求。模型发布日公开价格页尚未同步精确单价，因此不能把本地估算当作供应商账单。
程序临时按每百万输入1.5美元、输出9美元预留安全额度：完整返回用量估算0.255388美元，包含超时和
结果不明请求的全部预留上限约0.801708美元，低于1美元限制。

## 下一步

GLM值得继续作为首选调优对象。下一版应明确关闭或降低思考强度，把用户可见回答限制在约500字，
同时把总输出空间提高到4,000–8,000 token以容纳不可避免的内部过程。只重跑本轮三条不完整轨迹和
一条新的回撤留出样本；若完成率达到100%，再重跑全套确认。当前不连接全局AI网页，不部署NAS。
