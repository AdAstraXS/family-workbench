# 投研导航调整（2026-10-02）

## 页面归属

公司列表是唯一模块首页。搜索与单选筛选同排；持仓、研究进度、观察状态分别显示。
每份档案共用面包屑、公司切换器、四个研究阶段和两个辅助工具。辅助工具页不高亮研究阶段。

|位置|实际功能和兼容路径|
|---|---|
|研究准备／准备资料|`/research/<id>/materials/?context=prepare`，复用资料采集、重试与资料清单|
|研究准备／公司初识、问题与候选假设|`prepare/`、`prepare/?tab=questions`；历史报告、证据和三个后续选择保留|
|公司研究／研究总览、关键问题与证据|`company/`、`company/?tab=evidence`；官方、新闻、综合判断三部分不变|
|公司研究／更新公司研究|`analysis/`；一个生成入口，保留模型、授权和预算设置|
|公司研究／分析历史|`company/history/`；原 `analysis/<id>/` 与 `drafts/<id>/` 仍可阅读|
|个人判断／当前判断、判断历史|原档案详情、`first/`、`edit/`、`history/`|
|持续跟踪／公司动态|`follow/`；原 `company/?view=changes` 重定向到这里|
|持续跟踪／次日跟踪摘要、设置|原 `analysis/next-day/`，设置用 `?tab=settings`|
|持续跟踪／跟踪计划|原 `metric-focus/`，内含 `review-plan/` 财报复核计划入口|
|持续跟踪／复核记录|原 `reviews/`、`reviews/<document>/`，保存复核及原文引用|
|资料库|官方资料、富途资料、新闻外部资料、资料清单；保留文件目录、IR 目录、阅读、版本、原件和引用|
|财务与估值|原 `financials/`、`financials/futu/`、文件指标；`valuation/` 放原研究报告的估值试算，使用证券 ID 连接个股行情|

旧的混合证据筛选 URL `company/?view=evidence` 继续兼容，导航归入资料库。
原文引用锚点仍定位引用；其他研究链接保持滚动位置，后退恢复展开状态。
问题确认表单的未保存编辑仅暂存于当前浏览器会话，按档案、报告和保存版本隔离。

## 数据及分析边界

- 新增迁移 `0015_researchdossier_is_watched`：独立观察状态；将最新准备决定为“加入观察”的档案初始化为观察中。
- 字段设置数据库默认值，旧代码回退后仍能新建档案；回退代码无需撤销该增量字段。
- 修改观察状态仅允许档案本人编辑角色的 CSRF POST，不改变正式判断或 AI 自动对照授权。
- 已确认的候选假设可发起完整公司研究，无需先保存正式判断。报告冻结准备记录 ID 和版本；修改候选假设后提示旧背景。
- 候选假设阶段采用完整重评；正式判断下继续保留增量重评。次日跟踪原有前置要求与授权机制不变。
- GET 不采集、不调用模型、不写研究资料；保留原币种、会计准则和报告期。
- 不改动投资账户、交易、持仓或快照，不上传本地演示数据库。
