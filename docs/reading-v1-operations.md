# 在线阅读 M1–M3：运行与验收

更新：2026-09-26。实现范围见 [需求与设计](reading-v1-design-draft.md)，组件选型见
[开源调研](reading-v1-research-and-spike.md)，外部制作规范见 [成果格式 v1](reading-artifact-format-v1.md)。

NAS 已于同日上线，当前运行版本、备份及实际调度见 [生产发布记录](reading-nas-release-2026-09-26.md)。
以下开发验收记录保留当时的验证范围；生产实际调度为每 5 分钟、每轮各 1 个任务。

## 日常流程

1. 书架上传单本，选择仅自己/家庭共享；详情显示等待、处理、可读、失败或原件保留。
2. 阅读器自动保存个人位置。两个设备同时保存时，旧版本收到冲突提示，成员选择使用哪一处。
3. EPUB/TXT 和文字 PDF 选中文字保存划线与批注，默认私密。作者可分享、撤回、修改批注；
   可见成员可以回复，每人仅编辑自己的回复。批注的 UUID 地址作为稳定引用。
4. 我的读书计划支持多本书和目标日期，也可记录纸质书或外部阅读；到达 100% 不自动确认读完。
5. 上传外部 HTML，或者主动选择章节/小节/个人批注生成总结和导图。
6. 总结结果核对后保存为私密成果；发布后可修改正文、观点类型和导图标题，或上传新的 HTML。
   每次变更形成新版本。作者明确点击归档后，所选版本进入知识中心。

## 格式与资源上限

| 输入 | 阅读 | 划线批注 | AI 输入 |
| --- | --- | --- | --- |
| EPUB | 服务端规范化后按章节加载 | CFI + 章节 + 摘录 | 选章或章内完整摘录 |
| 文字 PDF | PDF.js 按页、鉴权 Range | 页码 + 相对区域 + 摘录 | 连续 1–20 页，可单页选择摘录 |
| 扫描 PDF | 支持 | 无文字层时不支持 | 无提取文字时明确拒绝；无 OCR |
| TXT | UTF-8 或带 BOM 的 UTF-16，最多 10 MB | 规范化分节后支持 | 按分节/摘录；分节不是原书章节 |
| MOBI | 保留原件，转换未接入 | 不支持 | 不支持 |
| 外部 HTML | 独立受保护预览 | 不转为图书正文 | 不自动发送给 AI |

书籍上传默认 256 MiB（`READING_MAX_UPLOAD_BYTES` 可配置），单本网页上传。
EPUB 展开上限 512 MiB、10000 项、单资源 16 MiB、XML 4 MiB；脚本、外链样式、字体混淆、
加密 EPUB 和独立 SVG 暂不支持。图片包装页内的栅格封面可保留。DRM/损坏文件不会绕过处理。
PDF 子进程内存 768 MiB、CPU 45 秒、墙钟 55 秒；加密、损坏、页段过大或超限会明确失败。

## 后台命令与运行状态

使用数据库任务和 Django 命令，不需要 Celery/Redis。部署时由现有受限 NAS 包装器接入
DSM Task Scheduler；本轮没有创建生产任务。

```text
python manage.py process_reading_imports --limit 3
python manage.py process_reading_ai --limit 2
```

建议分别每分钟执行，调度器避免同一命令重叠。数据库原子领取可避免重复处理；每次只处理排队项。
上传解析记录在图书详情的管理区；失败可重试，处理超过 15 分钟可重新排队。
AI 任务状态、错误、取消和输入快照在图书详情可查。运行超过 10 分钟的任务在下一轮标记中断，
不会自动重试可能已计费的请求。取消已发出的请求无法保证服务商停止计费，但其结果不会发布。
命令存在失败项时返回非零。管理员只读后台仍按业务权限筛选，超级用户不能绕过私密内容限制。

原件与规范化文件位于 `KNOWLEDGE_FILE_ROOT/reading`，纳入现有受保护知识文件备份。
不可只备份数据库：恢复须同时包含原件、规范化 EPUB 和成果 HTML。原件校验不一致时停止解析。
不要在有批注后静默重新规范化；位置同时绑定文件哈希与处理器版本。

## AI 配置

沿用 `AiProvider` 的 `openai` / `openai_compatible` 文本服务；排除图片用途模型。
使用服务商配置的模型和 HTTPS API，Key 只从现有环境变量取。阅读路径不支持内网端点或重定向。
本地模型制作 HTML 后上传不受此限制，也不需要配置在线 AI。

可在服务商非敏感扩展配置中填写：

- `reading_input_usd_per_million`、`reading_output_usd_per_million`：美元/百万 tokens 单价。
- `reading_data_retention`：供成员确认时查看的数据保留政策说明。
- `api_key_env_var`：沿用现有 Key 环境变量名，不能把 Key 本身存入数据库。

单次输入最多 12000 字；按序列化输入加提示词的字符数 × 2 保守估算输入 tokens，输出上限 2048。
这是估算，不保证所有模型 tokenizer 的精确用量；未知单价显示费用未知。
逐次确认页面展示完整输入、服务商、模型、发送地址、保留政策和估算。
确认后变更服务商/模型/相关配置会使旧任务失败并要求重新选择。确认前批注修改也会使快照失效。
请求无工具调用；书内文字视为不可信数据。结果必须符合结构、观点类型及引用范围校验。
服务商返回的正文/错误不会写入通用日志；实际私密输入和结果保存在仅发起者可见的阅读任务中。

## 权限与发布

图书权限是阅读、文件、批注、成果和知识归档的共同前提。个人进度与计划始终仅本人可见。
批注/成果分享分别由作者设置；分享成果意味着分享其中的引用快照。
知识中心归档采用独立阅读来源和版本投影，不套用人物成果的唯一键。
归档重复点击幂等；撤回图书或成果共享，知识详情、搜索及附件入口同步受限。
已经归档的内容和当时可见范围不会被编辑新版本覆盖；要归档新内容，主动归档新版本。

## 验证与上线边界

验证结果：PostgreSQL 16 下阅读与知识中心联合回归 **102 项通过**，含两客户端位置并发、相同成果并发发布、
私密/跨家庭/撤权、真实 PDF 提取、HTML 隔离响应、来源伪造、旧版本、AI 取消和模型变化。
Django 系统检查、迁移一致性检查和自有 JavaScript 语法检查通过。
独立测试设置的 OneNote 未配置提示是已知提示，不影响阅读模块；没有使用真实 OneNote 凭据。

本地使用独立 SQLite 预览和无网络、内存存储的 PostgreSQL 测试容器，均未连接 NAS 数据库。
正式 PostgreSQL 验证命令使用 `config.settings_reading_postgres_test`，只允许在可销毁测试容器内执行；
该配置不读取 `.env`。SQLite 快速回归使用 `config.settings_research_test`。

本轮已完成真实 EPUB/PDF 读取、划线保存、刷新恢复、调整字号、390px 响应布局、HTML 原始导图交互，
以及模拟 AI 的取消、结果发布、新版本、知识中心归档流程。HTTP 上传使用真实本地端点和 CSRF，
未将私人样本发送给云端 AI。

尚不能以此宣称全部设备已验收：Chrome 扩展拒绝自动选择本地文件，实际文件选择器上传未通过；
iOS Safari、Android 与平板真机未接入。桌面窄屏是响应布局测试，不代替触摸真机。
云端 AI 只完成协议与模拟结果测试，未对真实付费模型评估质量/延迟。
生产部署、DSM 调度、生产备份恢复、外网大文件上传和 NAS 新镜像构建仍属于上线验证。
新增 `pypdf==6.19.0` 后必须构建含该依赖的新镜像，不能只挂载源码到旧生产镜像。
