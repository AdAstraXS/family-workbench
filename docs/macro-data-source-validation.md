核验日期：2026-10-04（Asia/Shanghai）。状态：本地验证完成，尚未开发业务页面或部署。

后续进展：数据接入层与只读预览的实现、验证和部署限制见 [宏观数据接入层](macro-data-ingestion.md)。
补充核验：进出口原始金额须除以 100000 才是亿美元，不能照抄 AKShare 文档单位直接展示；
具体来源换算证据已记入接入层文档。

## 已确认范围

- 中国、美国分别展示；不做中美对照。
- 本轮不做 A 股盈利专题。
- 中国增加投资主题：固定资产投资总量、制造业、基建、房地产、民间投资、实际使用外资。
- 先复用免费接口和开源采集库，缺口才补小型官方来源适配器。
- 无 FRED API Key，本次仅实测无需注册的公开下载。

## 结论与判定标准

可用的基础组合是 AKShare（含统计局通用接口）+ FRED 公开 CSV。中国数据不能统一绑定东方财富：70 城宜优先统计局，社融/贷款结构需要央行补充，外商投资需要商务部补充。

本文件中的“可接入”只表示本次取得结构化数据、完成所列核验，可以进入实现；不表示长期稳定性、NAS 连通性、许可条件和所有历史值均已验收。

| 判定 | 含义 |
| --- | --- |
| 可接入 | 本地取数成功，范围/最新期和基础质量满足本次接入验证 |
| 需要补充 | 数据存在，但需补充来源、历史、口径处理或特殊解析 |
| 暂缓 | 本次未取得适合持续跟踪的完整来源 |

测试使用 Windows Python 3.13 隔离环境、AKShare 1.19.1，未改变应用 requirements。NAS 镜像使用 Python 3.12，后续必须另做兼容性与连通性验收。HTTP 请求设置超时、低并发；记录了失败、重试和参数修正。

## 关键质量发现

### 高：M1 历史余额和同比口径混杂

2024-08，东方财富接口的 M1 余额为 1049684 亿元，与央行新口径回溯余额一致，但同比字段仍为 -7.3%；央行回溯表的可比同比为 -3.0%。这是直接观察到的冲突，不能整列原样入库后作为连续可比序列。

处理：优先保存央行回溯值；保留旧/新定义版本；界面标注断点。不得混用新余额和旧增速。证据：`quality.json` → `checks.m1_definition_conflict`。

### 高：外商投资、社融和 ISM 的“成功但陈旧”

- `macro_china_fdi`：185 行，止于 2023-07。
- NBS 月度外商直接投资：119 期，止于 2019-11。
- `macro_china_shrzgm`：136 行，止于 2026-04；缺政府债券等完整当前结构。
- ISM 服务业：342 行，最后日期字段 2025-09-04；该字段不能未经映射就当统计月。

处理：外资改走商务部，社融/贷款结构改走央行，ISM 当前渠道暂缓。数据源健康检查必须核对“最新已发布统计期”，不能只看 HTTP 200 或抓取时间。

### 中：70 城上游截断、空地区和历史差异

- 东方财富去掉城市过滤、分页拉取仍只返回 10000 行，覆盖约 2014-10—2026-08；最早月份只有 60 城。不能因分页显示结束而声称历史完整。
- NBS 返回 71 个地区行，其中拉萨全部为空；实际有数据的 70 城在 2011-01—2026-08 共 188 期均完整。
- 四条核心序列总计 52640 个有效数值；与东方财富重叠的 40000 个单元格中有 2 个二手房同比指数差异：南宁 2020-09（东方财富 103.5，NBS 103.2），桂林 2020-02（105.7 vs 105.3）。差异原因未归因，可能涉及修订或整理差异，不直接称为录入错误。

处理：NBS 作主源；按官方 70 城名录和稳定地区码映射，不用返回行数代替有效覆盖。此处有效覆盖已核验，不代表其他面积分组/定基指数都可用；部分旧口径定基列在最新期为空。

### 中：GDP 和投资的累计/单季/基期

- 东方财富 GDP 表有“第 1—2 季度”等累计标签，NBS 提供单季和累计独立指标。首版以 NBS 定义为准。
- GDP 平减指数同比原型采用 `(本季现价GDP / 上年同季现价GDP) / (实际同比指数 / 100) - 1`，使用 Decimal 计算。
- 已完成 62 季试算，但实际增速输入经过舍入，所以只能称“测算同比”；不能据此声称得到了官方精确 GDP 平减指数水平，也不能跨不变价基期直接拼接名义/实际水平比值。
- 固定资产投资及工业利润优先保存官方“可比口径增速”。不能用两版历史绝对额重算后覆盖官方增速。
- 一月免报、1—2 月合并的缺口不是故障；不能拆成两个猜测单月。固定资产投资总量、行业和所有制维度不是互斥分项。

### 中：真实缺值与采集问题要分开

FRED 中 CPIAUCSL、CPILFESL、UNRATE、CIVPART 的 2025-10 存在空值；本次保留为空，未在本轮追究其统计发布原因。日度利率也有休市/假日空值。不得填零或跨月插值后冒充公布值。

PMI、LPR 首次请求超时后低频重试成功，表明需要有界重试，不构成长周期可用率证明。
