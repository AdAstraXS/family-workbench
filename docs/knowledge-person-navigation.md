# 人物管理与资讯导航调整

确认日期：2026-10-04。

- “新闻跟踪”和“精选订阅”独立位于“观察与分析”。精选订阅列表、阅读、上传和订阅管理
  使用一致的模块标题、选中状态和返回路径，保留原有节目、文字稿与自动任务。
- “AI 情报”位于导航末尾并标记“废案待处理”，保留旧页面、历史事件与原始链接。
- 知识中心“关注人物”提供“管理人物”、新增人物和编辑人物资料。姓名、简介、别名及历史作者
  关联不再要求跳到旧 AI 情报页面；原作者名、正文、专题成果与稳定人物标识保持不变。
- 人物维护不创建新闻关注、不启用信源、不调用云端 AI。浏览页面不写数据库。
- 人物目录仅展示与本家庭有关的人物；普通成员可以查看，家庭管理员可以编辑。跨家庭共用
  人物的基本资料保持不变，各家庭仍可分别维护自己的作者映射；同一作者不能同时归到两个人物。
- 底层仍复用现有人物与作者映射表。没有数据库迁移、历史数据转换或新后台服务。

验收覆盖：导航分组与单一选中项、精选订阅返回路径、旧链接可用、人物创建/编辑、作者冲突、
只读成员权限、跨家庭隔离、共用人物保护、原文保留，以及桌面和移动端阅读与编辑流程。
