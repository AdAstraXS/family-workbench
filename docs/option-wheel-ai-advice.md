# 期权车轮 DeepSeek 建议页

## 产品边界

建议页解释一份已冻结的规则决策，不能自行抓行情、扩展合约、修改价格和概率或改变候选资格。
它最多比较规则允许的三个代表合约，允许结论为暂不操作。不同候选互斥，不汇总权利金。
当前输入不含新闻正文和宏观日程，因此页面必须显示未覆盖，不能让模型凭记忆补充近期新闻。

模型输入使用显式白名单，只含标的代码、冻结行情、技术指标、财报/除息状态和候选合约公开字段；
不含账户名称、现金、NAV、完整持仓、原始供应商响应、日志或密钥。输入全文可在付费调用前展开核对。
候选身份和数字从服务器冻结输入展示，模型只输出理由和风险文字。

## DeepSeek 与费用

第一版固定复用唯一启用的 `deepseek-v4-flash` 和 `https://api.deepseek.com`，强制非思考模式、
JSON 输出且拒绝 HTTP 重定向。API Key 只从配置的环境变量读取，不进入数据库、命令行或模型输入。
模型价格按 2026-09-04 官方页面核对：cache miss 输入 $0.14/百万 Token、输出 $0.28/百万 Token；
实际价格可能变化，上线前及后续定期复核 [DeepSeek 模型与价格](https://api-docs.deepseek.com/quick_start/pricing)。

每次调用前使用 UTF-8 字节数加协议余量保守估算输入，并以配置的最大输出 Token 计算最坏费用；
单次上限取已有配置和 $0.01 的较小值。每家庭每日最多 10 个请求，失败也计入以避免自动重试费用。
结果保存实际返回 Token 和按已确认单价计算的费用估算；供应商未返回用量时显示“未返回”，不伪造免费。

## 任务与安全

- 只有本家庭超级管理员可勾选公开输入与费用同意后提交 POST；GET 永不调用 AI。
- 同一份证据、模型配置和提示词已有成功结果时直接复用；同一家庭一次只运行一项 AI 分析。
- 浏览器只轮询 GET。请求超时、网络失败或页面刷新不重发付费 POST，失败可能已产生费用并明确提示。
- 后台进程在调用前、保存前复核成员/管理员、服务商、模型、价格及提示词指纹；迟到结果不保存。
- 子进程只有固定 DeepSeek HTTPS 终点，响应最多 256 KiB。原始错误、响应和认证头不回显。
- 结果须匹配输入哈希和白名单候选 ID；未知字段、重复/新增候选、超长文本或矛盾结果全部拒绝。
- 结构校验不证明模型解释正确。页面持续标注 AI 观点、冻结时点、概率局限和“仅分析、不下单”。

## Futu 订阅决策

当前继续按需订阅少量候选并清理，不常驻整条期权链。Futu 官方说明连接关闭后会自动取消该连接订阅；
订阅不足一分钟时，要到一分钟后才释放额度。以后若实测按需订阅成为主要延迟，再单独设计有额度预算、
到期轮换和连接健康检查的小型常驻池，而不是删除反订阅逻辑。
