# 重要新闻初筛、正文与动态列表

2026-10-02。本轮已部署启用；已验证真实 Firecrawl 凭证与额度，尚待后续新候选验证正文质量。

## 已确认范围

- 规则先召回微软、Microsoft、MSFT、Azure、Copilot，以及算力中心、数据中心、AI 基础设施相关候选。
- GLM 根据标题、可用摘要、来源和发布时间，批量判断是否值得读正文。重大产品发布与能力升级可以入选，不要求新闻先提供实际收入数据。纯宏观、股价播报、普通教程、小修复和无新增事实的观点不优先读取。
- 初筛属于阅读预判。它不能确认利好、证明事件造成股价上涨，或替代正文分析。
- Firecrawl Cloud 单页取正文后，GLM 按正式投资假设逐项分析。用户正式判断保持原记录。
- 每家庭、每公司、每北京时间日最多 **3 次新网页正文请求**，跨信源和成员共用。失败和中断均占名额；零篇是正常结果。
- 初筛与正文分析共用现有模型日 ¥1、月 ¥30 限额。**Firecrawl 抓取额度独立计量，未计入 GLM 费用**，启用时需核对服务账户额度。

## 执行与限额

仍由 `run_investment_watch` 和既有 DSM 15 分钟任务执行。信源是否采集继续按各自 120 分钟间隔判断。

`INVESTMENT_WATCH_BODY_ENABLED=true` 后启用新流程；默认关闭。首次运行先保存启用时间，再进行采集，自动候选只处理启用后的新材料，且不自动处理发现超过 48 小时的积压。成员主动关联旧材料仍须通过初筛与限额。

正文优先读取 `FIRECRAWL_API_KEY`（或显式指定的环境变量），未填写时复用网页收藏的 `KNOWLEDGE_FIRECRAWL_API_KEY`。两个模块共用账户额度；不需要额外创建密钥。2026-10-02 只读核对 NAS 凭证有效，供应商接口返回套餐额度 1,000、剩余 1,399，周期至 2026-11-02。此数字只代表查询时状态。仅微软启用时，按每日三次上限，31 天最多新增 93 次正文请求；网页收藏用量另行占用同一账户。

初筛按模型输出上限分成小批，每轮最多四批。候选尚未筛完时留到下次任务，暂不花费正文名额；完成当前候选池初筛后，再按模型优先级、官方来源和发现时间排序。这里只能比较已经看到的新闻，不能保证后来发布的重要事件仍有当日名额。

新正文请求前在数据库事务中锁定家庭并预留名额。`BodyAttempt` 的唯一约束与每日计数覆盖所有相关信源和成员；同一输入的失败或未知请求不自动重复。已经保存的同版本正文、相同 URL 与相同内容版本、以及已有官方归档正文直接复用，不新增网页请求。已确认的重复关系继续共用原始候选。

初筛也先保存输入记录和费用预留；解析失败或中断不自动重复付费。无授权、模型停用、明显不足的模型额度或正文密钥未配置时停止对应请求。正文超出模型输入上限时保留原文供阅读，明确未生成分析，不悄悄截断后声称分析了全文。

## 正文与证据

- 固定调用 `https://api.firecrawl.dev/v2/scrape`，只取 Markdown，`onlyMainContent=true`、`onlyCleanContent=false`，关闭 PDF 解析，单次请求不重试。
- 只提交公开文章 URL，不提交个人假设、登录 Cookie 或模型凭证。校验公开地址，拒绝内网地址、带用户名密码的 URL 和非标准端口。服务请求保留 TLS 验证，拒绝携带密钥的 API 重定向。
- 2 MB 响应上限；空/短内容、明确的订阅登录提示、服务错误和不完整响应保留失败记录及原文入口，不作为成功正文。
- `BodySnapshot` 保存来源 URL、正文、SHA256、获取时间、抓取方式及压缩原始响应。新内容单独保存，AI 不覆盖来源正文。
- 分析缓存包含正文 ID 与哈希，`ThesisEvidence.input_body` 固定引用本次输入版本。引文与定位校验使用实际发送的标题和正文；旧摘要分析保留为历史。
- 抓取成功和引文匹配都不能证明来源事实或因果推断正确；付费墙、上游解析缺口和 AI 漏选仍可能存在。

接口配置参考：[Firecrawl 单页抓取文档](https://docs.firecrawl.dev/api-reference/endpoint/scrape)。

## 页面变化

投资动态列表突出标题、公司、来源和发布时间；发现时间放在次级信息。最多展开两条有方向的影响与原文短引文，其余判断及重复的“证据不足”折叠，完整依据仍可展开和进入详情。

公司、假设和方向筛选默认收起，已应用方向或假设条件时展开。手机上无需先穿过三行筛选框才能看到新闻。

候选与新闻详情可以展开保存的正文并核对版本。来源与运行页面显示正文开关、密钥配置状态、每家公司今日名额、本人初筛与正文请求记录；不展示密钥。查看页面不会触发采集、初筛或分析。
