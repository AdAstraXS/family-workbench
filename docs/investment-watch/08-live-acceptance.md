## 召回质量

使用用户批准的四项本机验收假设：AI 算力需求、资本投入的现金回报、云与 AI 实际收入、估值的经营和外部条件。它们不是生产正式判断。

主代理逐条开发标注 83 个冻结版本，34 条应作为候选。初始规则 TP 28、FP 1、FN 6、TN 48，精确率 96.55%、召回率 82.35%。遗漏包括英文 FOMC 标题、存储和债市；房贷政策为误选。调整双语关联词和房贷排除词后，同一开发集 TP 34、FP 0、FN 0、TN 49。

同一数据用于调整规则，不能将结果作为独立准确率。冻结规则后的 8 条新增材料逐条标为负例，没有误选；没有新正例，不能估计正例召回率。用户独立标注、更多正例和不同时间窗口仍是后续质量评估项。

`evaluate_watch_recall` 只读计算 TP / FP / FN / TN，并校验家庭、版本内容哈希、唯一 ID 和布尔标注。材料改变必须重新标注，不复用旧答案。

## 真实模型

经用户批准使用既有智谱 GLM-5.3 FlashX，测试总上限 ¥10。调用只在隔离脚本进程启用，网页服务的模型总开关保持关闭。凭据从已有环境配置读入内存，没有写入源码或报告。

价格依据：[智谱官方价格](https://docs.bigmodel.cn/cn/guide/start/pricing)，输入 ¥2 / 百万 token、输出 ¥7 / 百万 token；预算按非缓存价格保守计入。现有文本 Provider 接口以美元计价，用 [国家外汇管理局中间价](https://www.safe.gov.cn/AppStructured/hlw/RMBQuery.do) 2026-09-30 的 6.7351 做明确换算，不使用猜测的 1:1。

早期测试保留全部失败记录：外层 Markdown JSON 围栏、未知方向的 null 引文、过长输出截断、一次网络超时。修复围栏及空引文兼容，保留精确原文校验，方向性结论必须含引文和成立条件；已知返回用量的失败也如实计费，超时未知保留预留且同输入不自动重付。GLM-5.3 使用其低推理档及 4000 token 上限。

真实输出还暴露两项语义问题：将客户部署视为实际收入，将未经独立核实当作反面证据产生 mixed。提示词明确财务证据要求、正反证据要求及未提供公司关系的条件表达。提示词版本进入幂等键，旧分析保留；当前列表只采用最新成功批次，详情中的旧批次折叠为历史，历史不能追加当前复核。

最后六条质量样本包含：微软扩容、客户部署、OpenAI 行业新闻、长期美债收益率、只有标题的 FOMC 预测公告，以及不相关房贷政策。逐项检查原文引文、来源陈述 / 观点 / 推断、传导条件、现金回报与实际收入缺口。AI 结果仍需成员复核，精确引文不证明因果推断正确，少量开发样本不代表全量准确率。

最终提示词 `watch-evidence-v7` 的六条材料全部返回完整结果，共 24 项假设评估。微软扩容与客户部署是有条件需求支持；美债收益率通过明确折现率路径削弱估值外部条件；缺乏内容的 FOMC 标题及房贷新闻均保留未知。OpenAI 新闻只在确认实际合作和需求转化的条件下间接关联，不把公司关系说成输入事实。没有将这些材料推断为资本现金回报或实际收入增长。

累计 36 次付费测试，26 次完成、10 次失败，全部记录保留。按官方非缓存价格与返回用量核算的已知占用 ¥0.264521，另保留一次未知请求 ¥0.033555，合计预算占用 ¥0.298076。最后六条材料费用 ¥0.040764，平均约 ¥0.006794 / 材料；这是开发测试估算，尚未与供应商最终账单核销，不能外推为完整月成本。

从 `app/` 运行可复现的公开源验收：

```text
../.venv/Scripts/python.exe manage.py migrate --settings=config.settings_watch_validation
../.venv/Scripts/python.exe manage.py seed_watch_preview --settings=config.settings_watch_validation
```
