# AIHOT 借鉴与取舍 · v0.4

## 当前落实边界 · 2026-09-30

- 多源：已补自助 RSS/Atom、JSON、HTML 模板及测试预览；动态网站、登录和付费正文不承诺通用抓取。
- 两层筛选：新闻池与私人召回独立；已补规则预览、假设筛选和私人公司主题。关键词召回仍可能误选或漏选。
- 分析：保留一次逐假设分析，明确来源陈述、作者观点和模型推断，不恢复双评分、热点和日报。
- 聚簇：精确内容重复可以复用原材料分析；标题相似只给复核建议。管理员可确认重复、进展、冲突或撤销。确认无新增信息后才复用模型结果；不同解释和新增事实不自动丢弃。旧版本关系不自动搬到新版本。
- 综合：研究总览分开呈现投研、新闻、综合历史，综合输入使用来源材料快照。原始链识别仍依赖精确内容或人工确认，不能声称所有改写转载均已识别。
- 待验收：真实微软判断的人工标注集、真实模型推断质量和实际账单；当前合成测试只验证机制。

## 一致的处理链

```text
公开信源 → 增量获取 → 基础质量 / 财经宽预筛 / 同篇去重
                                 ├→ 新闻浏览（无个人分析也能读）
                                 └→ 个人规则召回或手动关联
                                      → 事件与新增信息
                                      → 逐假设关联及必要证据分析
                                      → 投资动态 / 必要复核
                                      → 已有公司研究综合评估
                                      → 成员决定是否修订正式判断
```

## 规则与提示词如何维护

前端补充（2026-09-30）：新闻浏览参考 AIHOT 精选的横向分类、搜索与日期时间线，卡片保留来源、标题、简介与操作。主题页参考其分组目录，改用投资相关主题；主题筛选只整理公共材料，个人判断仍进入原有研究流程。Demo 的主题由固定样本映射生成，不代表已运行自动主题识别。

可配置：来源选择、关联词、包含/排除、领域提示词、分析输出模板。提示词按步骤独立存放并版本化；改动后使用固定标注集对照漏选、误选与无依据推断。

必须由代码保证：成员权限、预算事务、时间与单位校验、引用有效性、幂等、版本冻结、更正撤回、正式判断只能由成员保存。不能把这些规则仅写进提示词。

缓存至少绑定成员范围、假设版本、材料版本、规则和提示词版本。同一原始链只处理新增信息；不能因多个媒体转载同一事实就重复付费或增加置信度。来源类型和报道数量是参考，不能自动证明真假。

## 微软样例的落点

1. 历史云收入披露进入新闻浏览，不要求先绑定微软个人判断。
2. 自动召回或成员手动关联后，成为微软研究候选；关联动作本身不证明投资逻辑。
3. 单项关系可支持云收入增长，同时对资本回报改善保持 unknown。
4. 与已有官方财报来自同一链的报道保留媒体解释，不新增独立事实权重。
5. 新证据综合进新研究分析；已有分析记录保留当时输入和时间。资料失效或判断改版后，相关证据关系待复核。
