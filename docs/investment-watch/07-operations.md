# 可用版运行与上线 · v0.4

## 日常新增公司和来源

关注设置 → 添加关注公司 → 搜索已有证券或填写名称/代码/市场 → 建立本人探索档案 → 编辑关联词 → 预览 → 确认保存。勾选“启用自动关注”后后台才会自动召回；即使未启用，主题页的“我的关注公司”仍可阅读匹配材料。新增档案不推定持仓或创建正式判断。

来源与运行 → 添加信源 → 选择 RSS / JSON / HTML 或已适配网站 → 测试读取 → 核对前五条标题、链接和日期 → 保存为暂停来源 → 启用。编辑后重新测试；签名 30 分钟内有效。JSON 字段映射使用点号对象路径，HTML 使用 CSS 选择器和 @属性，页面提供示例。采集始终走公共 HTTP 防护，不发送登录凭据，不执行配置脚本。未知日期保留未知。

材料详情 → 事件与证据关系 → 复核重复、进展或矛盾。只有确认无新增信息时选择重复；此后共用原始材料分析。原始材料改版/撤回后重新核对；错误关系可追加 independent 撤销，历史记录保留。

本机浏览器验收脚本为 scripts/check-watch-browser.cjs，使用独立 Edge 无头会话，仅固定访问 127.0.0.1:4319，使用本机演示账号。它会在隔离预览库添加/复用苹果探索档案并保存演示关注规则，不应指向生产。

## 本机试用

正式 Django 页面为 `/research/watch/news/`，当前本机监听 `127.0.0.1:4319`。
这是隔离预览库，不加载生产 `.env`、NAS 数据或 API Key；公开新闻是真实采集，微软研究判断明确为演示。

从本项目 `app/` 运行（先在虚拟环境安装已有 requirements.txt）：

```powershell
../.venv/Scripts/python.exe manage.py migrate --settings=config.settings_watch_local
../.venv/Scripts/python.exe manage.py seed_watch_preview --settings=config.settings_watch_local
../.venv/Scripts/python.exe manage.py runserver 127.0.0.1:4319 --settings=config.settings_watch_local
```

本机预览账号 `watch-preview`，口令 `watch-local-preview`。此账号只存在于 `.watch-local/preview.sqlite3`，禁止把本机设置用于对外服务。初始化命令在其他 settings 下拒绝执行。

已保存的数据在重启后保留。原 4318 静态 Demo 仍用于设计对照，不是正式业务入口。

### Windows 登录后恢复预览（2026-10-01）

本机任务 `FamilyWorkbench-LocalInvestmentPreview` 在当前用户登录后运行
`scripts/keep-investment-preview.ps1`，维持 4319 可用版与 4318 静态 Demo。
两个服务均只监听 `127.0.0.1`。任务使用当前用户的普通运行级别，不保存密码。
每 30 秒检查端口，服务退出后尝试恢复；日志保存在 `.watch-local/preview-supervisor.log`
及对应服务的时间戳日志。该任务不会执行迁移、采集或模型调用。

一键恢复并打开新版 Demo：运行 `scripts/open-investment-preview.ps1`，或双击项目根目录的

停用自动恢复可在 Windows 任务计划程序中禁用上述任务；已运行的服务需另行停止。

## 采集与后台

```text
python manage.py run_investment_watch --family <已核对的家庭ID> --seed --no-analyze
python manage.py run_investment_watch --family <已核对的家庭ID>
```

`--seed` 仅补齐未配置来源，默认暂停；不覆盖来源设置。管理员在“来源与运行”启用所需来源。
总开关和限额见 `config/investment-watch.env.example`。采集与模型分别关闭；打开模型仍须成员在关注设置明确授权。

NAS 使用 DSM Task Scheduler，每 15 分钟调用一次上述管理命令。来源默认间隔 120 分钟；同一家庭有 20 分钟数据库租约，每轮最多 8 源、3 个档案任务、每任务 3 个候选。每条模型请求最长 60 秒，不启动网页内后台线程、不新增 Redis/Celery。实际调度命令必须按现有部署技能核对容器、家庭 ID 和日志位置。

网页 GET 只读。成员主动保存规则时对最新 500 条现存材料匹配；定时循环也执行匹配。目录源只采集近 90 天的已知日期新闻，日期未知的条目单独标记。列表来源窗口有限，不能保证高频新闻零遗漏。增量内容更新追加版本，不更新旧引用。

任务中断后，租约到期才可接管。已有费用预留或失败记录的同一模型输入不会自动重付；成功记录复用。对于明确证明未发出或未计费的请求，首版暂由管理员核对账单处理，不提供“一键清零额度”。

## 模型配置与授权

- 复用已获准的投研文本 Provider、现有 API Key 环境变量及出站 HTTP 防护。
- Provider `extra_data` 额外填写 `watch_usd_cny`，表示当前确认的美元兑人民币费用换算值；不自动猜测汇率。
- 全局模型开关、有效 Provider 价格、密钥、成员对个人假设的明确授权、可用预算全部满足，才调用。
- 端点/模型/计费配置变更使授权签名失效，需重新确认。
- 默认日限额 ¥1、月限额 ¥30，是家庭共享的本模块模型额度；含选定新闻的公司综合分析也占此额度。
- 未纳入新闻的原有公司研究、其他模块和服务器费用不计在本模块额度中。总运行目标 ¥30–60 仍需结合它们核算。
- 调用前行锁预留；超限停止。失败或缺 usage 保留预留。实际费用高于预留会如实记录并停止后续调用，管理员核对后处理。
- 方向性证据必须有当前材料中的精确引文；这验证出处，不证明模型的因果判断正确。无充分材料应为“证据不足”，重要结论由成员复核。

## 来源实测（2026-09-30）

| 来源 | 读取范围 | 实测 | 边界 |
|---|---|---|---|
| 华尔街见闻 | 公开快讯列表 | 成功 | 最新有限窗口；可能含其他媒体转载 |
| 智通财经 | 首页公开标题、目录简介 | 成功 | 部分条目无可靠日历日期，保持未知 |
| 财新金融 | 公开目录标题、简介、日期 | 成功 | 不抓付费正文；原文可能需订阅 |
| 美联储 | 官方货币政策 RSS | 成功 | 官方政策源，英文材料不做全量付费翻译 |
| 虎嗅 | 移动公开首页 | 失败：未识别文章链接 | 不绕过访问限制，保留失败状态，可暂停 |
| 已归档 SEC / IR | 工作台现有官方资料与版本 | 离线适配测试 | 不另行下载，没有归档就不伪造覆盖 |

未知时间不填采集时间。同标题的不同日期不是同一事件；未带日期的跨站相似材料不自动合并。人工合并可撤销，并保留原事件、个人收藏和引用；合并不代表独立印证。
上游删除不等于正式撤回，列表源未提供撤回标志时无法自动检测；需要人工核对原文。规则主题及预筛是首版机制，后续按漏选样本扩充。
