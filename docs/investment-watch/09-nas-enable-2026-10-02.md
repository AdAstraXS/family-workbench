## 配置与调度

生产 `.env` 在备份后只追加以下四项：

```dotenv
INVESTMENT_WATCH_COLLECT_ENABLED=true
INVESTMENT_WATCH_MODEL_ENABLED=true
INVESTMENT_WATCH_DAILY_CNY=1
INVESTMENT_WATCH_MONTHLY_CNY=30
```

原文件字节保持前缀，权限保持 0600；通过受限包装器 `recreate-web` 仅重新创建网页服务以载入环境。没有构建新镜像或改变依赖。

DSM 任务 `family-workbench-investment-watch`，ID 15，root，已启用；每天 00:00–23:45、每 15 分钟。只读核对 scheduler 与系统登记均为分钟 0、15、30、45；保存时下次触发为 2026-10-02 17:30。状态读取末尾的 `get status ... failed` 是 DSM 状态读取限制；已核对完整任务字段、启用状态、调度登记和两次实际运行日志。

```sh
cd /volume1/docker/family-workbench || exit 1
exec 9>logs/investment-watch.lock
/usr/bin/flock -n 9 || exit 0
date -Iseconds >> logs/investment-watch.log
/volume1/@appstore/ContainerManager/usr/bin/docker compose exec -T web python manage.py run_investment_watch --family 1 --seed >> logs/investment-watch.log 2>&1
```

来源失败、部分失败或分析受阻时命令返回非零，并追加日志。文件锁和数据库租约避免并发重复处理。`--seed` 只初始化不存在的暂停来源，不覆盖已保存状态。
