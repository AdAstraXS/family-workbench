# 公司新闻筛选与正文复用

## 共用流程

公开来源每轮读取一次，匹配所有已启用关注规则。公司别名、产品名称、行业关键词，以及已登记的
公司官方域名均可产生候选；排除词和包含词仍生效。官方来源也进入候选，避免新品名称尚未加入
词表时漏掉发布公告。候选相关性不等于重要性，更不等于利好。

有正式研究判断和有效个人模型授权后，定时任务批量初筛标题、可用摘要、来源和发布时间。
共用的重要性条件包括重大产品变化、商业化、订单、成本、资本开支、财报指引、竞争与监管。
不强制与已有假设完全重合；纯宏观数据、股价播报、教程和小修复不优先读取。

初筛同时返回公司直接相关／行业关联／联系不明及理由。行业事件须说明公司影响路径。
最近三天最多十二条已选事件加入同一个请求，减少跨轮重复阅读；本批重复只能指向已选条目。
新增事实、矛盾和无法确认重复的材料仍独立判断。AI 去重只是阅读建议，不自动确认事件合并，
也不共用已确认分析。全部来源和旧判断仍保留。

## 每家公司独立配置

关注设置中直接编辑，无需新代码分支：

| 字段 | 含义 | 微软配置 |
| --- | --- | --- |
| 公司名称与别名 | 公司身份和代码 | 微软、Microsoft、MSFT |
| 产品与业务名称 | 不写公司名的产品事件也可召回 | Copilot、Azure、Microsoft 365、GitHub Copilot |
| 关联行业与领域 | 候选线索，AI 还需解释传导路径 | 数据中心、算力、AI基础设施 |
| 官方域名 | 原始来源识别、官方候选和阅读排序 | microsoft.com |
| 业务关注说明 | 该公司主要业务与关注变化 | 云和AI商业化、数据中心供应、客户订单等 |

例如另一个标的可以配置自己的产品、行业和官方域名，随后预览召回并保存。新建公司默认关闭
自动关注和模型授权；正式判断、成员授权、提供商策略都由现有流程核对。标准化不自动为其他
公司启用 GLM，也不增加第三方供应商。

## 正文与引用

- RSS `content:encoded` 或 Atom 内嵌 `content` 可直接固化为正文快照；普通 description 不当作全文。
  短内容、明确的继续阅读／订阅提示以及超过保存上限的内容不提升为正文。保存原始片段和规范
  文本的校验值，展示时转义；RSS 仍可能省略内容，完整性需要核对。
- 已保存 RSS 正文、官方归档正文和完全相同的来源版本可直接复用，不发送新 Firecrawl 请求。
- 其他重要候选使用 Firecrawl 单页抽取。每家庭、每证券、北京时间每天最多三次新请求；失败和
  中断也计数。不同成员与来源共享该公司的名额。
- 公司综合评估在成员选中材料后使用保存正文，冻结正文 ID、正文哈希、实际发送的文字和引用
  区间。资料包过大时明确阻止发送，不静默截断正文；历史报告不随新正文改变。
- 初筛与正文分析共用模块每日 1 元、每月 30 元预算。未来同时启用多个公司仍共享这个预算，
  并非每家公司单独获得 30 元。没有重要事件时允许零抓取。

## 阅读与纠错

动态页默认展示最近 72 小时的已选事件；“全部候选与历史”保留未入选和历史内容。显示关联
类型、摘要／正文状态和筛选理由，少量有方向的变化优先，其余判断折叠。详情页“我认为这条
重要”记录成员理由并进入优先阅读队列；仍检查当前版本、权限、授权、预算和每天三次上限。
未知或失败的请求不因此被自动重试。

Firecrawl 共享账户额度由定时命令每天最多查询一次；页面只读缓存。新闻和知识库在查询后的
消耗仍以服务商账户为准。额度耗尽时暂停新的新闻正文请求；账户状态失败不会泄露请求或密钥。
来源显示下一次采集时间、最近新增数和连续异常次数，HTTP 条件请求游标与运行统计分别保存。

## 本次来源调整

仅对已经授权的微软档案所在家庭补充 Microsoft 365 与 Azure 官方 RSS，保持两小时间隔；
财新金融目录暂停并保留历史。与现有华尔街见闻、智通财经、微软总博客构成五个活动网络来源。
已归档官方研究资料继续复用。虎嗅与美联储仍按原状态保留。旧文章只归档；超过 48 小时的旧
发布不自动消耗初筛和抓取额度，成员主动选取的历史材料仍可处理。

官方 RSS 地址已以 HTTP 200 与有效 RSS XML 验证。Firecrawl 账户接口根据
[官方额度文档](https://docs.firecrawl.dev/api-reference/endpoint/credit-usage)使用
`GET /v2/team/credit-usage`。

## 验收边界

专项测试覆盖全文与摘要区别、正文变更版本、完整评估输入、跨轮重复及新增进展、域名边界、
人工纠错的权限与幂等、额度与名额、来源迁移幂等、失败游标和 GET 不联网。浏览器检查桌面与
390px 手机阅读流程。技术测试不能证明大范围新闻召回率；真实模型筛选应逐条对照保存的输入
与来源，用有明确标签的样本评估，不把“没有新候选”报告成筛选成功率。
