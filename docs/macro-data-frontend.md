# 宏观数据页面与指标百科

宏观模块面向家庭成员日常阅读，按中国、美国分别组织数据，不提供中美对比或 A 股财报分析。
所有入口要求登录并遵循有效家庭成员权限；普通成员和只读成员均可查看。页面只读取已入库数据，
不在 GET 抓取来源或写入观测。数据接入、修订与运维约束见 [接入层说明](macro-data-ingestion.md)。

## 页面职责

- `/macro/`：国家入口、未来一周官方发布计划、最近发布及百科入口。最近发布按已记录的官方发布日期
  排列，报告及统计期合并展示，城市不重复计数；没有发布日期的观测不参与，绝不用抓取日补位。
- `/macro/country/CN/`、`/macro/country/US/`：国家内主题导航、关键指标、单指标趋势和指标列表。
  中国默认投资主题，美国默认通胀主题；“全部”显示每个主题一个代表指标的紧凑全景表，
  不再显示前三个通胀卡片或默认通胀趋势。每行保留各自统计期，可进入主题或指标详情。
  不把不同单位的数值合并排名。70城总表仅保留在中国房地产主题及城市指标详情入口。
- `/macro/indicators/<country>/<code>/`：趋势、最新统计期、分页历史、口径及来源。原有
  `/macro/series/<pk>/` 地址仍可用；`/macro/?country=CN|US` 兼容原有入口。
- `/macro/encyclopedia/`：按名称、代码、别名搜索，并按国家和主题筛选，每页 12 项。
  基础概念解释同比、环比、累计、指数、百分点、季调、实际值、折年、存量和修订等。
- `/macro/encyclopedia/<country>/<code>/`：注册的 95 条序列均有统计范围、计算方法、公式、假设例子、
  统计方式、意义、常见误读、同国家相关指标和方法来源。与实际趋势双向跳转。
- `/macro/observations/<pk>/revisions/`：查看该统计期实际采集到的版本与证据。第一版是首次采集，
  不能据此宣称是历史首次公布值。
- `/macro/sources/`：恢复来源总览，区分原发布机构、分发平台和获取方式；按指标列出实际历史范围、
  有效值数、来源缺值数、地区数和最后采集核对时间，并可按国家及名称/代码/来源筛选。
- `/macro/sources/runs/`：单独保留采集运行状态、结果和错误，与来源覆盖互相链接。
- `/macro/calendar/`：按月份、国家、计划/实际筛选；桌面月历与手机日程明细。计划来自核验后的
  官方日程快照，实际日期来自观测的 `release_date`，二者分开，不将已过的计划自动当成已发布。
- `/macro/housing/cities/`：按单一月份显示全70城新房/二手房环比及同比，主位为变化率，小字保留指数。
  默认最新已有月份；已有记录可进入该城市历史。缺值、未导入、指标停用分别标出，不跨月份补齐。

## 展示与口径约束

趋势提供 1、3、5 年和全部范围，按该指标所选地区的最新统计期向前取值。历史表与曲线共用地区
和范围，分页不改变曲线数据。月度、季度、年度日期展示实际统计期；官方发布日期缺失时明确标记。

70 城四类住宅序列存储原始指数，页面主位展示“指数 − 100”的环比/同比变化率，可切回原始指数。
单城市默认北京市；选择城市后，指标详情、百科及返回实际趋势继续保留城市。城市数值必须与城市名
一起展示，不冒充全国汇总。PMI 参考线为50，原始住宅指数为100，变化率曲线参考线为0。

数据库与页面保留 `Decimal` 数字文本，不以浮点数推算增速。前端 `Number` 仅用于 SVG 坐标和轴刻度；
原始值保持来源精度；比值计算的增长率使用48位 Decimal 运算并在展示时四舍五入到两位小数，
指数减100的变化率保留来源精度。缺值不归零、不沿用前值；曲线在明确缺值处断开。一个统计期
只显示一个点并说明不能形成趋势，整个范围缺值时不绘制曲线。

美国通胀、GDP、工业生产、零售、实际收入/消费、工资及住房数量等以增长变化为主，原始水平为次要信息。
详情、国家关键卡片、指标列表和历史表采用相同计算，趋势可切换同比、环比、原始值及适用的其他口径。
美国非农主位为月新增（千人），由相邻月人数相减，同时提供同比/环比。GDP 区分同比、季度环比和季度
环比折年，实际GDP默认环比折年；GDP平减指数也提供折年变化。失业率、参与率、储蓄率、利率、PMI
本身就是有意义的比率或指数，不再套百分比增长；首次申领仍以周度人数为主。

CPI 的同比使用新增 `CPIAUCNS` / `CPILFENS` 未季调基数，环比使用原有 `CPIAUCSL` / `CPILFESL`
季调基数。PPI同样以 `PPIFID` 计算同比、`PPIFIS` 计算季调环比，最终需求包括商品与服务。
辅助基数在来源与百科可核查，国家日常列表隐藏三条辅助序列，避免重复展示。
未导入对应未季调序列时，同比显示“暂无可比数据”，不以季调同比代替。PCE 使用其季调序列。
公式按[FRED说明](https://alfred.stlouisfed.org/help)、[BLS公布口径](https://www.bls.gov/news.release/archives/cpi_01132026.htm)
和[BEA折年说明](https://www.bea.gov/help/faq/122)核验；计算结果不冒充另行采集的官方公布增长率。

同比严格比较相同月份/季度，环比严格比较上个月/季度；基数缺期、缺值、非正数时不计算，不能把最近
一条有效记录当作上期。趋势截短不会丢失计算所需的范围前基数，所有结果都来自当前已入库版本，
不能冒充历史当时可见版本。中国已有对应同比序列的金额指标（零售、利润、投资、外资、M2、社融余额、
单季GDP）主位显示原始金额，增速在同主题的独立指标展示；趋势仍可切换来源发布的对应增速。
缺少来源发布的增速时不以金额强算替代。年度现价GDP提供名义同比，比较上一年年度现价金额；
实际GDP同比取可比价格指数减100，不冒充实际季度环比。缺少可靠同比/环比基数且原始值有效时，
主位及默认趋势回到原始值；零值也属于有效数据。
中国投资、利润、外资、部分贷款及财政按累计口径展示，累计指标不计算相邻累计金额的环比。
社融余额与融资增量分别解释，人民币外资金额不与旧美元金额混接。

## 发布日历维护

`app/macro/release_schedule.json` 保存2026年163条核验计划和机构来源，核验日期为2026-10-05。
覆盖国家统计局相关主要报告，以及BLS就业/CPI、BEA GDP/个人收入与支出、Census零售/住房报告。
春节导致2026年2月PMI于3月4日发布等例外按官方表逐条录入，不靠“每月某日”的猜测规则。
美国时刻使用 `America/New_York` 转 `Asia/Shanghai`，自动处理夏令时，实际发布日期无时刻则仅显示日期。

日程当前随源码快照更新，尚无自动刷新；年度或官方修订后须重新核对来源、日期、时刻及覆盖统计期，
更新快照再运行测试。超出已核验年份显示“尚未录入官方计划”，不生成假日期。
人民银行、商务部未来发布日期以及周/日度报告尚未覆盖，不推测日程；已有实际日期仍可查询。
美国FRED CSV本身不提供正式发布日期，现有该类观测不进入总览最近发布；不得以本日抓取、FRED更新日
或计划日填入 `release_date`。完整“最近发布”覆盖仍需后续核验官方实际发布证据。

百科教学数字与实际观测分离。解释内容在 `app/macro/guides.py` 和 `guide_examples.json`，来源为统计局、
央行、商务部、财政部、海关、BLS、BEA、Census、美联储、纽约联储、财政部与 Freddie Mac 的公开方法资料。
新增或改变注册指标时须同时更新百科和测试；遇到统计制度变更先核对当期附注与版本，不能仅改文案
就混合历史观测口径。文档中的链接解释方法，观测值的准确来源以修订证据为准。

## 验证方式

在独立测试库运行，不对本地应用库或 NAS 生产库导入验收样本：

```text
docker compose exec -T -e DJANGO_SETTINGS_MODULE=config.test_settings -e WORKBENCH_TEST_DB=test_macro_frontend web python manage.py test macro --keepdb
docker compose exec -T web python manage.py check
docker compose exec -T web python manage.py makemigrations --check --dry-run
git diff --check
```

针对性测试覆盖所有95条序列的百科及未接入页、统计期与精度、城市隔离及跨页面保留、范围与分页、筛选搜索、
停用指标、GET 无采集或写入、成员/只读成员/停用成员和未登录权限，保留接入层的幂等、修订与并发测试。
并覆盖CPI季调/未季调分离、GDP折年与季度环比、缺期/非正基数、来源实际历史范围、70城单月缺值及
不跨期填充、日历夏令时与春节例外、实际日期合并、最近发布排序不使用采集日。
浏览器验收应检查国家和主题切换、增长口径与原始值切换、时间范围、城市总表、来源筛选、日历、百科搜索和返回趋势、修订证据，以及桌面、手机
信息层级与横向溢出；仅证明页面可访问不足以完成验收。

官方发布稿需要已入库的明确来源地址。缺少历史的指标只能展示实际已有观测；页面不会补造历史数据。
数据源自动发现、历史回补、镜像依赖及 NAS 定时运行的实施，继续遵循接入层说明和部署技能。
