# 图书删除与回收站 · 2026-10-02

## 使用方式

- 上传人在图书详情页点击「删除图书」，查看影响说明并勾选确认，图书移入回收站。
- 在线书库的「图书回收站」只列出本人删除的图书，可恢复到原来的可见范围。
- 删除后所有成员的书架、阅读器、下载、批注和阅读成果入口均不可访问；原文件、阅读进度、
  批注、讨论、计划和成果保留。已归档到知识中心的独立资料仍可查看。
- 待生成的 AI 任务取消，恢复后需要重新确认；正在生成的任务完成后才能删除。
- 重复上传回收站中的原文件会提示恢复，不新增重复图书。
- 本版不提供永久清除，回收站不释放磁盘空间。
