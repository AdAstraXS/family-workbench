# 基金定投

入口：投资组合 → 基金定投，路径 `/portfolio/fund-dca/`。

## 数据与金额口径

- 一条计划对应一个六位基金代码及份额类别；同一基金可被不同成员或不同计划使用。
- 全部人民币。每次金额、固定手续费百分比、余额和余额日期由成员维护。0是已确认零余额，
  空值是未知；余额与日期必须同时填写或同时留空。
- 每年计划次数：日252、周52、月12、季度4、年1。年额＝每次金额×次数，月额＝年额÷12。
  起止日期不折算实缴；每次手续费＝每次金额×费率÷100，四舍五入到分，单独展示。
- 本模块不产生交易流水、不参与投资组合持仓或资产快照，不按净值估算个人余额或收益。
- `FundDcaPlan` 存计划，`FundDcaChange` 存修改审计；版本检查避免旧页面覆盖新修改。
- `FundReference` 存共享公开资料和最新净值，`FundNavRecord` 按基金/净值日期唯一；
  `FundDisclosureSnapshot` 按基金/报告日期唯一，分别保留资产分布和持仓来源、抓取时间。
  `FundRefreshRun` 记录后台更新状态和各基金结果。

## 数据来源与限制

本地和NAS的Futu OpenD均已核对：016452、270023、050025查不到有效基金净值资料。
净值使用天天基金的固定基金代码接口，JSON常量安全解析，不执行返回的JavaScript。
雪球/蛋卷提供基金介绍和资产分布；介绍失败时使用天天基金基本资料。
持仓为天天基金披露的前十大股票，保留实际报告日期，不能理解为实时完整持仓。
公开网页接口可能变化；部分失败保留此前成功数据，在页面列出异常。

比例保持来源的“占基金资产净值比例”，不归一化，合计可能超过100%。
050025的目标ETF513500关系按基金正式报告明确记录；目标ETF的资产和股票比例单独展示，
不将“其他”强行改称ETF，也不计算为联接基金或家庭余额的穿透比例。
单位净值走势展示原始数值，不用于计算分红、拆分后的收益。
未识别的基金不猜测目标ETF关系。

## 权限与更新

家庭内全部成员可查看；管理员维护全部成员，成员仅维护自己，查看者只读。
网页GET只读取数据库；新增、编辑计划后排队更新；“更新基金数据”通过POST执行，
成员只请求自己基金，执行时重新检查成员权限。管理员后台仅提供只读核查。
每只基金使用PostgreSQL会话锁防止重复抓取；写入以基金/日期唯一键幂等更新。
后台任务使用现有资源槽和15分钟上限，不额外引入Celery/Redis。

DSM Task Scheduler每日运行，网页按钮用于补充更新：

```sh
cd /volume1/docker/family-workbench
/usr/local/bin/docker compose exec -T web python manage.py refresh_fund_data
```

应使用现有任务计划中Docker的实际路径；日志输出保存到NAS日志目录，失败返回非零状态。
无计划时命令不创建演示计划或基金；生产数据只能由成员实际录入。
