# 文字模型的模块默认选择

管理员在 Django 后台的 **AI 分析 → 模块默认模型** 中，为每个模块选择默认文字模型。登记 API 地址、模型名和费用边界仍在 **AI 服务商**。配置只影响新发起的任务；已保存的 AI 结果和审核记录保留原模型信息。选择其他模型不会自动重发失败任务。

| 模块 | 默认选择的作用 | 逐次覆盖 |
| --- | --- | --- |
| 期权分析建议 | 发起规则分析后、用户勾选 AI 时使用；只发送公开市场指标 | 暂无；当前仅支持已验证的 DeepSeek Flash |
| 投资研究 | 投研表单优先选中该模型 | 仍可在本次表单改选，且每次确认私人判断和 SEC 摘录的云端发送 |
| AI 情报 | 自动任务和未指定模型的调用使用；网页选择器优先显示该模型 | 手动情报分析仍可逐次改选 |
| 知识整理 | 来源未单独指定模型时使用 | 来源已有 `ai_provider_id` 时优先遵循来源配置；保留原有云端授权 |
| 全局 AI | 只保存未来默认值 | 全局对话服务尚未上线，不会因此产生调用 |

部署时会把现有“DeepSeek 文本整理”的模型名更新为 `deepseek-flash`，并保留其环境变量密钥和其他现有扩展配置；如果现有 DeepSeek Pro 已有完整投研授权，则将同一投研策略复制给 Flash 并更新计费上限的单价。DeepSeek Pro 行保留供历史记录与人工比较。新增 `glm-5.3-flashx` 文字服务商，初始仅获准接收公开情报元数据；其费用门槛采用保守美元估值。图片识别服务商不变。

期权逐合约建议在 GLM FlashX 的真实样本中曾出现数字、货币和排序错误，因此当前不允许把它选为期权默认模型。投资研究需要显式的模型数据与费用策略；知识整理的来源云端授权目前不包含跨服务商切换。此限制会在后台保存时给出提示，不会绕过现有授权。
