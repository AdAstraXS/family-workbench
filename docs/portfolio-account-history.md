# 证券账户历史年份口径

年份选择展示该年最后一份家庭本位币快照。账户余额、持仓数量、价格、成本和浮盈均来自这份快照，不能混用当前持仓。无快照时显示无数据。

“累计已实现盈亏”是已录入的有效流水（部分成交、已成交）截至快照日期的历年累计，不是年度收益。流水按交易日期截止；快照保存后补录的历史流水可能尚未反映在已保存资产中。年度总收益和现金流收益率另行定义，本次不引入。

统一币种折算依次使用：同一家庭快照明细保存的汇率、同日正式家庭账本的汇率、截止快照日可用历史汇率。不同展示币种通过同一快照本位币换算。冻结汇率冲突或缺失时，相关汇总显示未知，不能跳过该币种后显示部分合计或 0。

历史账户范围包括当时有流水、资金、持仓或快照证据的账户；后来停用的账户仍可查询。没有历史余额证据的账户显示缺少明细；未来开户不能显示为当时的零余额账户。账户详情保留年份。快照日盈亏未计算，明确显示“未统计”。
