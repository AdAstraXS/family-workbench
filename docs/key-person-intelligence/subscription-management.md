# 精选订阅统一管理

家庭管理员在「精选订阅 → 管理订阅」使用同一列表管理原有四个公开信源和后来添加的公开信源。列表不标识来源是预设还是成员添加，统一提供搜索、类型筛选、编辑、暂停／恢复和删除。服务密钥与月预算仍在次级配置区。

编辑页可预览最近内容是否命中筛选规则。预览只读取来源列表，不保存订阅、不提交转写任务或 AI 摘要。保存时不勾选自动摘要，后台仍收集命中节目，但不自动转写或整理；勾选后首次只处理最新一条，此后只处理新发布内容，仍受全局转写／摘要授权与月预算限制。

原有四源保留其专用适配器和出版方原文规则。编辑名称、标题包含／排除词、星期、时长及自动整理开关不会更换适配器。更换类型或地址会先验证新来源，建立新订阅，再停用旧订阅；旧节目和版本继续关联旧来源，不改写历史来源身份。

文章没有节目时长，不能设置最短时长；原有「视野环球财经」官方频道列表也不提供时长，该来源暂不接受时长筛选。表单会明确报错，不会静默排除全部节目。

删除是可审计的移除：记录操作成员和时间，停止后续检查与处理，从管理列表隐藏。旧节目、文字稿、摘要和知识归档保持可读。正在抓取或整理时拒绝删除，避免已提交任务在操作后继续产生费用。B 站无法自动读取频道列表的 UP 主仍可逐期添加公开视频，管理页明确标记该状态。

`intelligence.0013` 新增移除字段；`intelligence.0014` 为部署时已有家庭补齐四源的显示名称和地址，未订阅的来源以暂停状态建立记录。两步迁移不会触碰投资组合事实表。
