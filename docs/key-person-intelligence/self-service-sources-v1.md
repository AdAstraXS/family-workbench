# 精选订阅自助信源（第一版）

## 范围

家庭管理员可在「精选订阅 → 管理订阅 → 添加公开信源」添加公开 YouTube 频道或播放列表、
B 站 UP 主、播客 RSS、文章 RSS。保存前展示最近内容及筛选命中情况。成员可从精选订阅页上传
TXT、SRT、VTT、MP3、M4A、MP4、WAV、WebM；上传内容仅本人可见，归档到知识库后仍为私人资料。

首版不接入 Patreon 会员页，也不保存带访问令牌的 RSS。B 站单条公开视频可由家庭管理员逐期添加；
频道自动列表需在目标 UP 主页面实际验收，平台返回 352/HTTP 412 时以逐期添加为准。

## 筛选与费用

- 标题包含词可选「任一」或「全部」，另有标题排除词；词或短语以逗号分隔。
- 发布星期按北京时间判断，节目延期发布会被排除；最短时长只对可核实音视频有效。
- 订阅首次最多收集三篇，只对最近一篇命中内容按「自动整理」开关处理；之后只对新发布内容自动处理。
- 收集与列表预览不调用收费模型。音频转写和 AI 摘要仍受家庭现有授权与月预算约束；
  上传音视频还需该次单独授权转写，上传文字稿的 AI 整理也需该次单独授权。
- 上传文字稿原件与临时音频在 NAS 加密存储。文字稿原件仅上传者可下载；临时音频完成后或
  六小时后清理。云端转写仍会把获授权音频传给百炼。

## 操作与验收边界

新增信源失败时不保存订阅；暂停保留已收集内容。RSS 正文若无法确认完整、文章页需要登录，
任务明确报错，可由成员上传已有文字稿。B 站单条视频会核对 BV 编号、UP 主、公开状态和时长；
若后续音频下载被平台限制，条目留在阅读列表并显示失败原因，不自动绕过限制。

上线验收应检查：筛选预览与定时任务结果一致、首次收集不批量计费、重复运行幂等、
上传权限隔离、转写预算、NAS 依赖镜像、生产迁移、DSM 任务日志和桌面/移动页面。
