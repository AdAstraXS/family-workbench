# M3.2 真实文本分析边界与样本验收

状态：Implemented and validated locally

更新时间：2026-08-16

## 1. 正式模型与数据边界

本地已登记的“DS文本整理”指向 DeepSeek 官方 API `https://api.deepseek.com`，模型为
`deepseek-v4-flash`。官方模型与价格页确认该模型支持 JSON Output；本阶段使用非思考模式，避免摘要任务
产生不必要的推理 Token。

- 官方模型和价格：<https://api-docs.deepseek.com/quick_start/pricing/>
- 官方 JSON Output：<https://api-docs.deepseek.com/guides/json_mode/>
- 官方思考模式：<https://api-docs.deepseek.com/guides/thinking_mode>
- 官方隐私政策：<https://cdn.deepseek.com/policies/zh-CN/deepseek-privacy-policy.html>

DeepSeek 隐私政策没有给 API 输入提供“零留存、绝不用于模型改进”的明确承诺。因此家庭工作台只能发送
已经公开的新闻标题、发布者、发布时间和短摘录；不得发送家庭知识正文、付费全文、Cookie、密钥、成员
备注或其他私人信息。若以后需要分析这些内容，必须重新选择服务商并单独确认授权。

## 2. 单次调用上限

正式配置采用 `public-metadata-v1`：

- 最多 8 条已保存证据，每条短摘录最多 2,000 字符；
- 系统提示与事件 JSON 合计最多 20,000 字符；
- 输出最多 1,800 Token，DeepSeek V4 明确关闭思考模式；
- 输入按每百万 Token 0.14 美元、输出按每百万 Token 0.28 美元做保守估算；
- 单次最坏费用估算不得超过 0.01 美元；
- 实际响应按 `prompt_tokens` 与 `completion_tokens` 记录保守费用，缓存命中仍按较高的未命中价格估算；
- 相同事件、证据、模型和版本默认复用已有结果，不重复调用；只有管理员显式“重新分析”才产生新费用。

价格复核日为 2026-08-16。价格可能变化，替换模型或价格复核过期时应先更新 Provider 配置，不应默认
沿用历史单价。

| 本地事件 | 代表问题 | 人工期望 |

## 4. 每条验收标准

真实结果需逐条人工核对：

1. 中文摘要只包含标题和短摘录可支持的信息，并至少引用一条实际证据。
2. 事实、观点、数字的引用 ID 全部存在；媒体判断不能伪装成公司事实。
3. 证据不足时明确写入 `uncertainties`，不得调用模型记忆补齐正文细节。
4. `event_type` 与人工期望一致；首轮均应采用 `change_type=unknown` 或仅在证据充分时采用 `new`，
   不能凭单条新闻判断增强、弱化或转向。
5. 两次强制运行的摘要措辞可以不同，但事实、数字、证据引用和核心特征不应发生方向性漂移。
6. AI 结果不自动发布、不自动收藏、不自动归档，也不自动合并事件；最终分层仍由 `people-v1` 代码计算。
7. 每次成功或失败都有请求审计、Token 与费用记录；超出输入或费用上限时必须在联网前拒绝。

## 5. 真实运行结果

本地已配置 `KNOWLEDGE_TEXT_AI_API_KEY`，Provider 页面状态为可调用。首次 #11 尝试被本机代理的
Fake-IP 防护在联网前拦截，同时发现错误提示字段名写错；修复后，直连 Fake-IP 仍被拒绝并留下 1 条
失败审计，没有 Token 或费用。随后复用项目既有思路加入显式启用的公开 DoH IPv4 回退，真实连接仍用
目标域名做 TLS 证书校验，并拒绝 DoH 返回的本机或内网地址；默认不开启兼容开关。

首轮 Prompt v1 的 5 条样本全部取得结构化结果，但人工验收发现四类需要收紧的行为：模型会按“某人
表示”把收入变化误分为发言，会在摘要中省略媒体观点的归因，会把厂商速度主张写成独立实测事实，并
可能遗漏大额计划的期间与承诺口径。M3.2 因此将 Prompt 升级为 `intelligence-event-v2`：事件类型改按
底层动作分类，摘要与事实保留说话主体，标题数字缺少期间、范围、承诺程度或衡量方法时必须列入不确定
项，单条证据无法比较历史时采用“无法判断”。

Prompt v2 的 5 条样本均通过人工基线：

- #11 保留 210 亿美元、二季度末和经 xAI 间接持有关系，并列明持股比例与投资时间缺失；
- #12 纠正为 `business`，明确内容为 CFO 表述，并列明收入数字、期间和比较口径缺失；
- #14 纠正摘要归因，把离职作为事实，把“可能打击 IPO”作为 CNBC 观点；
- #16 将 14 倍写为来源主张，并提示衡量标准、预览范围和定价均未知；
- #19 把融资动作与 TechCrunch 评论分开，并补充计划期限、承诺程度与具体机制缺失。

对 #12 和 #19 强制复跑：#12 的分类与六项特征完全一致；#19 的摘要、事实、观点、数字、分类和不确定
方向一致，原始投资相关性从 90 变为 70，代码重要性从 83 变为 78，但两次都保持“待复核”。这说明模型
特征适合辅助排序，不适合作为发布、归档或精选的唯一决策，最终层级继续由代码和人工复核控制。

本次共取得 12 个成功响应、1 个联网失败审计，成功响应保守费用估算合计 0.002272 美元。当前每个样本
只有一个 Prompt v2 当前版本，历史版本均保留；没有自动发布、收藏、归档或合并事件。
