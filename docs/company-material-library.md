# 公司基础资料库

## 使用流程

投研 → 公司研究 → 先了解一家公司 → 搜索名称或代码 → 明确选择上市市场 → 公司资料。
已有档案可从公司研究页的“公司资料”链接进入。原公司研究、个人判断、财务概览及官方资料入口保留。

公司资料页有三个区域：资料阅读、五步资料清单、获取与更新。网页 GET 只读；POST 才会搜索外部数据或启动获取。
获取在独立进程中进行，每项最多 360 秒；一个家庭同时最多两家公司，同一证券只允许一个活动任务。
同一任务重复提交返回已有任务。中断任务可重试；失败不删除旧资料。尚未配置定时获取，本阶段为按需增量更新。

## 数据口径

- 严格按 SEC / 富途返回的原始币种、原统计口径显示，不按上市市场推定财报币种，不进行货币换算。
- 财务运算使用 Decimal。金额可缩写为万、亿，显示两位小数和千分位；每股金额单独标注。
- 同名指标、不同币种、不同期间、不同会计准则不混合汇总。
- 主营构成不同维度可能重叠，原占比也可能包含抵销和特殊口径，不强行归一化成 100%。
- 公司搜索只接受明确选择的普通股结果。相关公司、ETF 和衍生品不自动视作目标公司。
- 多地上市关系来自已核对目录，未知关系不自动合并；个人研究档案不跨成员或跨证券自动合并。

## SEC

支持 10-K、10-Q、8-K、20-F、40-F、6-K 及修正案。最近目录优先保留三份年报、四份 10-Q 和各三份近期公告。
年报不会被大量 6-K 挤出默认资料集。6-K 不能直接当成季报。
主文件限额从 20 MiB 调为 40 MiB；通过 SEC `index.json` 发现 HTML/PDF 附件，排除单独的 XBRL 展示表。
每个报告默认取得前十二份附件，最多登记一百份附件供单项获取；更早历史目录作为线索保留，未承诺全量历史归档。
已归档且无错误的相同 accession 自动沿用本地正文；用户显式更新单项时重新核查。
companyfacts 同时保留 US GAAP、IFRS 及每条数据的原单位、申报日、accession。阅读表先呈现常用核心年度指标。
PDF 图片和超过提取限额的内容会保留原件并明确提示正文缺失，不进行 OCR 或猜测。

## 富途

接入概况、三张财务报表及主要指标、主营构成、晨星全文、评级、行业归属和产业链线索。
所有财务接口都不传 `currency_code`，使用来源原币种。
产业链列表使用接口返回的游标，不将页码冒充游标；首屏少量链和关联公司的原始结果保存本地。
产业链名称和环节只提供研究线索，不代表已证实的客户或供应商关系。

目前 OpenD 部分财务报表的 `display_name` 为空。仅采用 SDK 原名、已有证券专属的人工核对映射，
或同一证券的富途公开财报页字段定义；公开页补齐须核对证券、报表类型、报告期、币种、字段结构和金额。
公开页是季度口径时额外读取同口径 API 结果核对，再为该公司同表字段补名，不改变年度数值。
页面访问限速，不尝试绕过 403；字段未核对时保留原始记录，主表显示待补充提示，不显示裸字段编码。
市场、接口权限、历史报表和第三方报告的实际覆盖存在差异；未取得的资料不能标记为分析已完成。

## NAS 持久化和权限

`CompanyIdentity` 保存证券身份、已知上市关系和 CIK。
`CompanyMaterial` 保存来源项目与最近检查结果；`CompanyMaterialVersion` 追加不可变原件、整理数据、正文和日期。
原件为 gzip 二进制，附 SHA-256，存放在 NAS PostgreSQL 持久卷，随数据库备份一起保护。
JSON 接口保存 SDK 返回数据的序列化记录；HTML/PDF 保留下载字节。相同原件及整理结果不新增版本。
现有 `OfficialResearchDocument` / `OfficialResearchContentVersion` 保留，不批量迁移或覆盖旧原件。
阅读和下载均要求拥有当前研究档案；原件以附件下载，禁用浏览器内容嗅探和执行。
任务记录含私密档案身份，仅通过所属成员页面查看，不开放管理员跨成员入口。

五步清单记录材料版本引用、报告期、抓取时间和缺项，供后续 AI 使用；它不等同于已执行五步 AI 分析。
既有 SEC/IR 正文也纳入清单；只有原件但没有正文的报告不当作可读证据。

## 验证

2026-10-01：本机隔离 PostgreSQL 投研回归 396 项通过，包含并发重复归档、重复任务启动、访问隔离、
GET 不采集、原币种显示、20-F/40-F/6-K 与修正案、IFRS 年度重述选择等。
实际样本包含 JPM、NIO、BABA、TSM、腾讯、比亚迪港股/A股、贵州茅台；SEC 补充 ASML 与 RY。
ASML 24,864,729 字节年报成功提取 1,379,558 字符正文。公开字段补齐存在时效和访问限额，不能声称所有字段已齐全。

部署记录在生产验收后补充。
