# 个股行情与估值

入口：投资组合 → 自选股 → 股票名称或“个股行情与估值”；持仓中的股票名称也可进入。公司研究页提供返回入口。页面只支持系统内已有的股票；访问权限沿用家庭持仓和自选股范围。

页面 GET 只读取缓存，不连接 OpenD，也不写数据库。首次打开若尚无缓存，浏览器以 POST 获取一次；缓存超过 24 小时也会在页面显示旧数据的同时后台更新，失败后至少间隔一小时才自动重试。用户随时可点“更新数据”。请求发出后立即显示加载状态。每个来源独立处理失败，旧缓存继续可用，并显示失败原因。

数据口径：

- 行情快照、历史前复权日线：富途 OpenD。最新价与日线可能有不同的市场时点，页面分别显示日期。
- PE、PB、PS 的 1/3/5 年历史、当前值、平均值、分位数、前瞻值：直接使用富途 `get_valuation_detail`。只抽样历史点用于绘图，不自行重算倍数、平均值或分位数。
- 分析师共识和最近机构评级：富途研究接口；目标价仅标注来源和日期。
- 晨星：仅保存星级、公允价值估计、护城河和不确定性等结构化字段及日期。完整研报正文、PDF 和长文本不入库，也不送 AI。
- 均线、RSI、量比和候选支撑/压力区：从已保存的前复权日线计算。候选区间需近 120 个交易日内至少两个局部转折点，聚类宽度为最新参考价的 2%；它不是买卖建议。

富途 API 的具体接口可能随 OpenD 版本、行情权限、市场和标的覆盖范围而缺项。运行镜像需安装 `futu-api>=10.6,<11.0`，并能连接已配置的 OpenD。刷新不修改持仓、交易、正式公司判断或财务概览。
