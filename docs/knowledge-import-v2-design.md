# 家庭知识底座第二版：Markdown / HTML 历史资料批量导入

更新时间：2026-08-08

> 当前状态：已完成微信公众号 HTML 的本地开发和 5 篇真实样本试导入；资料默认进入统一知识底座的历史归档，代码待部署到 NAS，
> 尚未写入生产 PostgreSQL 或生产知识文件目录。Markdown 需取得真实样本后再接入。

## 1. 已确认的导入规则

- 微信公众号同一篇文章的 HTML、PDF、DOCX、Markdown 和 MHTML 内容重复，当前只采用 HTML。
- 主动导入的历史资料是成员人工精选的可信归档，确认批次后默认直接进入统一知识底座的“资料库 → 公众号历史归档”，不进入待整理，也不直接占据“精选知识”。
- 同一篇文章只保存一份；资料库、公众号来源账号的历史文章和精选知识都是同一文档的不同视图。成员在人工整理页把“资料库层级”提升为精选知识后，才进入精选知识视图。
- AI 摘要、分类和标签默认关闭，只作为以后可选的整理任务；导入不依赖 AI。
- 原始 HTML、相对目录、文件名、标题、作者、发布日期、本地图片、封面和原文链接尽量完整保留。
- 先上传或暂存原始包，再异步生成只读预览；只有成员再次确认后才创建知识文档。
- 重复导入相同内容时跳过；同一篇文章内容变化时新增不可变版本，不覆盖原始版本。
- 回滚只撤销该批次创建的文档或版本；如果文档在导入后被人工修改，自动回滚必须停止并报告。
- 网页长期保留单个 HTML 或 ZIP 的手工增量上传入口。

## 2. 数据与任务设计

### 2.1 权威原件和来源

- 上传包和每篇原始 HTML 使用知识底座的受保护文件存储，不由 Web 服务器直接公开。
- `KnowledgeSource` 新增 HTML/Markdown 导入来源类型；公众号按成员和来源名称建立稳定来源。
- `KnowledgeRevision.normalized_hash` 保存规范正文与本地图片组合哈希，用于幂等和重复判断。
- `KnowledgeAsset.source_path` 保存图片在导出目录中的原始相对路径。

### 2.2 批次审计

- `KnowledgeImportBatch` 记录原始包、SHA-256、格式、默认分类/可见范围、状态、预计空间、
  新增/更新/跳过/重复/错误数量和完成/回滚时间。
- `KnowledgeImportItem` 逐篇记录相对路径、稳定 ID、标题、作者、日期、原文链接、原文件哈希、
  规范哈希、图片清单、预览结论、警告/错误，以及导入前后的文档和版本引用。
- 预览、正式导入和回滚均复用 `KnowledgeJob`/`KnowledgeJobItem`，支持排队、心跳、计数、错误报告
  和任务审计，不在普通 HTTP 请求中解析或写入文章。

### 2.3 处理流程

1. 保存原始 `.html` 或 `.zip`，计算包 SHA-256；此时不创建知识文档。
2. 后台预览校验 ZIP 路径、文件数、展开体积、单文件体积和异常压缩率。
3. 从微信公众号 HTML 提取正文、标题、作者、发布时间和原文链接；纯文字动态可从页面元数据恢复。
4. 按导出器的目录和图片序号匹配正文图与封面，校验图片 MIME 和文件签名。
5. 生成净化正文和纯文本，只保留允许的标签、属性和链接协议；脚本、评论区、广告、iframe、
   事件属性和未落地的远程图片不进入正文。
6. 计算稳定公众号 ID 与规范哈希，给出新增、更新、内容未变、强重复或错误的逐篇预览。
7. 成员确认后，后台任务为有效项目创建或更新知识文档；状态直接设为“已入库 / 已规范化”。
8. 回滚时逐篇校验当前版本和文档更新时间；存在后续修改时保守失败，不覆盖成员新工作。

## 3. 网页和命令入口

- `/knowledge/imports/`：上传 HTML/ZIP、查看最近批次和安全边界。
- `/knowledge/imports/<批次>/`：查看空间估算、SHA-256、逐篇预览、警告/错误、确认导入和回滚。
- 首页“上传资料 / 导入记录”和“来源与同步”页均可进入批量导入页面。
- `stage_knowledge_html_import`：从受控本地目录选择少量 HTML 与配套图片，生成受保护试导入包。
- `queue_knowledge_import_batch`：在人工检查后排队正式导入或回滚；实际执行仍由现有知识任务执行器完成。

私密批次只有发起成员能查看逐篇标题和错误；家庭管理员可以看到批次级运行状态，但不能查看其他
成员的私密逐篇内容。只读成员不能上传、确认或回滚。

## 4. 五篇真实样本试导入

从 408 篇公众号 HTML 中选择了时间跨度、文件体积、正文图片和格式差异较大的 5 篇：

| 样本 | 代表性 | 预览结果 | 保存图片 |
| --- | --- | --- | ---: |
| 想不出标题 | 最早文章，2022-11-05 | 新增 | 1 张封面 |
| 上了深刻的一课~ | HTML 体积较大 | 新增 | 1 张封面 |
| 让我再看你一眼~ | 多图正文 | 新增；2 个远程图片位置无本地文件并明确警告 | 10 张正文图 + 1 张封面 |
| 美股大暴跌…… | 无标准 `#js_content` 的纯文字动态 | 从元数据恢复正文；作者回退为批次公众号名称 | 0 |
| 有所爱，无所畏~ | 最新文章，2026-05-09 | 新增 | 1 张封面 |

本地隔离预览结果为 5 新增、0 更新、0 重复、0 错误，共 14 个图片文件，预计保存约 3.4 MB。
正式试导入后 5 篇均进入历史归档视图，原始 HTML 全部存在，正文图片全部使用受保护的本地地址，
正文无脚本和远程图片引用，AI 摘要保持为空。再次预览相同资料时 5 篇全部判定为“内容未变化”。
整批回滚后 5 篇试验文档全部撤销，原始批次包和 SHA-256 仍保留。

本次试导入使用独立 SQLite 数据库和独立知识文件目录；没有连接 NAS 或生产 PostgreSQL。
